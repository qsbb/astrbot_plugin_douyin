# 真实环境验收

验收对象为“拾趣”项目的“凝心溯溪-趣”插件，当前开发版本为 `0.0.1`，Page 入口名为“拾趣 · 抖音工作台”。

本文件是后续验收步骤。当前未登录真实抖音账号、未安装到用户的运行中 AstrBot、未执行真实点赞、评论、@、私信或转发。

2026-09-10 在本机做过独立匿名浏览器的公开首页只读探测：HTTP 200，但正文停留在 `Please wait...`，没有视频元素、业务响应或可用的 `data-e2e` 控件。插件已增加 `PAGE_NOT_READY` 识别，并保留首次登录窗口供人工操作。这次探测不能代替实际账号验收，也不足以判断等待页的具体原因。

## 已验证与未验证的分界

本地页面测试确实运行 Chrome、执行 JavaScript、触发请求并读取响应，但页面是测试构造的数据。它证明账号与目标校验、提交回执处理等代码流程；**不能证明测试中的 DOM 属性已经存在于当前抖音网页**。

`data-conversation-id`、`data-conversation-panel`、消息方向/发送状态、提及选项 UID、分享面板选中状态、原生卡片回执等定位是当前适配约定。转发回执还需要 `data-message-id`、`data-receipt-id` 或 `data-share-receipt-id` 中的稳定标识，并且该标识在本次发送前不存在。缺少这些字段时不能确认成功。实站验收必须采样真实页面后调整 `douyin/locators.py` 和对应操作代码，不能向页面注入自造身份属性再把结果称为平台原生证据。

点赞、评论接口路径有公开源码参考，但页面签名、交互结构和账号可用性仍需实际验证。不得把接口返回 HTTP 200 单独当作成功。

## 第一阶段：宿主加载和只读页面

1. 确认 AstrBot 版本、Python 环境、插件安装目录、浏览器可执行文件与 FFmpeg。
2. 加载开发插件，确认 13 个 `douyin_*` 工具的参数完整、管理员命令权限生效。
3. 保持写权限关闭，打开 **拾趣 · 抖音工作台** Page，接管浏览器，在画面中扫码/短信登录；核对当前账号并点击绑定，确认 `/dy status` 看到同一真实 `user:UID`。
4. 验证当前用户接口能够识别账号；遇到人工验证则完成验证，不能添加绕过逻辑或拿 Cookie/昵称冒充 UID。
5. 分别验证推荐、搜索、作品详情、评论分页。记录对应响应路径和脱敏数据形状，确认作品 ID 一致。
6. 用已知内容的视频检查音轨来源、实际分析时长、采样秒数与字幕提取；测试无音轨、无模型、超大小、超时和取消。

采集用于开发的样本时只保存必要的 DOM/JSON 结构，去掉 Cookie、Authorization、登录 Token；不要导出整个浏览器配置目录。

### Page 专项验收

1. 切换 Dashboard 中英文及明暗主题，确认页面元数据和正文同步变化；窄屏仍可点击所有控件。
2. 在无桌面的部署环境首次打开浏览器，二维码可见；手机号与验证码可从 Page 输入，手动滑块可拖动。此项需要用户本人完成，离线测试不能代替实际登录。
3. 已通过聊天命令登录的会话在 Page 显示同一账号；Page 登录后，归还控制再运行 Bot 只读工具，无须重新登录。
4. Page 接管时并发调用 Bot 工具，确认收到 `ACCOUNT_CONTROLLED`；归还或五分钟无画面/输入请求后恢复。
5. 刷新后的旧画面 ID、越界坐标、不支持按键和任意导航被拒绝；操作中若跳出允许的抖音域，停止控制并允许从固定首页入口恢复。
6. 保存 Page 授权配置后立即生效，重载后仍在；保存失败不产生虚假的运行授权。绑定取自当前真实账号。
7. 页面禁用或插件卸载后原 API 返回 503；空身份、API key 和前端伪造身份不能操作。
8. 结构化写动作断线后，按原 request_id 查询回执；不会因页面刷新而自动重发。人工点击仅报告输入发送，结果在平台画面中核对。

## 第二阶段：低频站内写操作

只有用户明确授权真实目标和动作后才执行。配置动作持续授权用于以后运行，不自动代表本次开发会话获得了真实社交操作权限。

| 项目 | 核对重点 |
|---|---|
| 点赞 | 先读实际状态，再设置目标；同一意图重复调用不切换；刷新详情再核对 |
| 评论 | 正文一致、视频 ID 一致、回执有评论 ID；提交与公开可见性分别记录 |
| 回复 | 被回复的评论 ID 必须确定；不得仅点击重名用户旁的“回复” |
| @ | 选择的是稳定 UID 对应的实际用户；原生编辑实体和回执中的 text_extra 均可验证 |
| 私信 | 会话 ID 与目标用户对应，新增消息属于该会话，并有平台发送状态证据 |
| 原生转发 | 原视频卡片 ID、接收 UID 与回执一致；发送普通 URL 不算原生转发 |
| 中断 | 提交后断开页面、工具取消或宿主停止，必须保留 unknown_result，不能自动再次提交 |

## 第三阶段：系列联动和发布

核纳管、模型路由字段补齐、主 Agent 与记忆/知识插件接入均单独做契约验收。确认原主链路的人格与交付流程仍然负责最终说话，本插件没有额外发送聊天平台消息。

当前源码未包含主动定时刷视频、兴趣演化、自动回复策略、跨平台发消息、抖音移动端驱动、多账号并行、自动验证绕过或签名逆向模块。若网页的稳定身份不足以支持某个站内动作，应保留不可用状态，并基于真实证据决定后续适配方式。
