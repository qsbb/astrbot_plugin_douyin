# 拾趣 · 凝心溯溪-趣

为 AstrBot 提供抖音浏览、搜索、视频理解和互动工具。你可以在 **拾趣 · 抖音工作台** 中登录、操作 Bot 使用的抖音账号，也可以让 Agent 通过工具完成操作。

[下载版本](https://github.com/qsbb/astrbot_plugin_douyin/releases) · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/qsbb/astrbot_plugin_douyin/issues)

## 功能

- **发现内容**：浏览推荐、搜索视频、读取作品信息和评论。
- **理解视频**：结合视频音轨与采样画面，调用已配置的语音识别和视觉模型。
- **分享互动**：点赞、取消点赞、评论和回复；提供实验性的 @、抖音私信和原生视频转发工具。
- **页面操作**：扫码或短信登录，点击、输入、滚动、手动拖动，以及账号绑定、授权设置和操作记录查看。
- **共用账号**：Page 与 Bot 使用同一份登录状态，支持人工接管后再归还给 Bot。

## 安装

需要 **Python 3.12+、AstrBot 4.28 至 5.0 之前的版本**，以及支持工具调用的对话模型。

在 AstrBot 插件管理中，通过以下仓库地址安装：

```text
https://github.com/qsbb/astrbot_plugin_douyin
```

也可以从 [Releases](https://github.com/qsbb/astrbot_plugin_douyin/releases) 下载插件 ZIP 安装。

### 准备浏览器

保持 `browser_channel` 留空即可使用内置 Chromium。插件加载后会在后台自动检查、下载匹配版本并验证启动，首次准备进度会显示在 Page 中；完成后继续打开登录画面，无需进入终端手动安装浏览器。

浏览器保存在 AstrBot 数据目录，后续启动会复用。更新 Playwright 或浏览器文件缺失时，插件会重新准备匹配版本。下载失败可在 Page 点击 **重试准备**。

首次准备需要可用网络和可写的数据目录。Linux 缺少系统运行库时，插件会在已有 root 权限且具备 `apt-get` 的环境中自动补齐；权限不足或系统不受支持时会显示具体原因。无桌面环境会自动使用无窗口模式。

如果希望使用已安装的 Chrome 或 Edge，可将 `browser_channel` 分别设为 `chrome` 或 `msedge`。这两种模式使用系统浏览器，不会替换或安装系统中的 Chrome/Edge。修改配置后重载插件。

### 启用视频理解（可选）

安装 FFmpeg，并在 AstrBot 中配置语音识别（STT）和支持图片输入的视觉模型。需要指定模型时，填写插件的 `stt_provider_id`、`vision_provider_id`；这两个字段填写 **Provider ID**。FFmpeg 不在 PATH 中时，通过 `ffmpeg_path` 指定其可执行文件。

只使用搜索、作品描述和普通互动时，无需配置视频感知模型。

## 第一次使用

1. 打开 **插件详情 → Pages → 拾趣 · 抖音工作台**。
2. 点击 **登录 / 打开浏览器**。首次使用时等待自动准备完成，页面会继续打开登录画面。在画面里扫码；使用短信登录时，先点击画面中的输入框，再通过下方输入栏发送手机号或验证码。
3. 登录完成后，点击 **刷新状态**，核对当前账号，再点击 **让 Bot 使用当前账号**。
4. 在 **Bot 授权** 中启用插件。用 AstrBot 管理员账号在聊天中发送 `/dy status`，把返回的 `umo` 和 `actor_id` 分别填入页面 **聊天调用权限** 中的会话名单和调用者名单，保存配置。
5. 点击 **归还给 Bot**，之后就可以在聊天或 Page 快捷操作中浏览、搜索和查询内容。
6. 需要互动时，勾选对应动作并保存。转发、私信和 @ 还需要先通过联系人或会话查询工具核对对象，再把返回的标识加入允许互动的对象名单；名单使用标识，不使用昵称。

Page 中的启用、账号绑定和授权设置保存后立即生效；在 AstrBot 原生配置中修改浏览器、模型等设置后，需要重载插件。

聊天调用权限用于 Bot 工具。你在 Dashboard 中手动登录和操作浏览器时，无需先填写聊天会话名单。

### 接管、归还与暂停

- **接管浏览器**：由你直接操作画面，Bot 暂时不能同时操作这个页面。
- **归还给 Bot**：恢复 Bot 的浏览器操作。页面停止请求画面和发送输入后，接管权也会在五分钟后自动释放。
- **暂停 Bot 操作**：停止后续工具操作；需要继续时点击恢复。归还浏览器不会自动解除暂停。

## 在聊天中使用

完成登录和授权后，可以这样提出要求：

> 搜几个关于猫咪的抖音视频。
>
> 看看这条视频主要讲了什么。（附上视频链接）
>
> 给刚才那个视频点个赞。
>
> 把这条视频转发给已经授权的朋友。

具体调用哪些工具由 Agent 决定。需要在抖音内执行点赞、评论、转发或私信时，聊天调用者还必须具有 AstrBot 管理员权限。

视频读取提供三种深度：

| 模式 | 作用 |
|---|---|
| `metadata` | 仅读取作品描述和元数据 |
| `preview` | 分析前最多 20 秒音轨及采样画面，默认模式 |
| `full` | 分析至插件配置的时长上限 |

视频分析会返回任务号，Agent 可查询进度和结果。采样画面与作品标题不能代表整段视频的全部内容。

完整工具列表与参数见 [工具说明](docs/AGENT_TOOLS.md)。

## 管理命令

以下命令需要 AstrBot 管理员权限：

| 命令 | 用途 |
|---|---|
| `/dy status` | 查看登录与运行状态，以及当前会话的授权标识 |
| `/dy login` | 在有桌面的 AstrBot 主机上打开登录浏览器；远程部署优先使用 Page |
| `/dy pause` | 暂停后续 Bot 操作 |
| `/dy resume` | 恢复 Bot 操作 |
| `/dy receipts` | 查看最近的站内操作回执 |

## 常见问题

| 情况 | 处理方法 |
|---|---|
| 浏览器正在准备 | 等待 Page 中的下载和启动检查完成；通常仅首次安装或更新浏览器时需要准备 |
| 浏览器准备失败 | 查看 Page 中的具体原因并点击“重试准备”；检查服务器网络、数据目录权限以及系统运行库的自动安装条件 |
| Page 没有画面 | 点击“登录 / 打开浏览器”，查看准备进度或具体错误。账号状态暂时无法查询时仍可查看画面 |
| 工具提示未启用或未授权 | 检查插件开关、聊天会话和调用者名单；互动操作还需勾选对应动作 |
| 提示浏览器正在被人工接管 | 在 Page 点击“归还给 Bot” |
| 提示账号不一致 | 在 Page 核对当前登录账号，重新绑定后再操作 |
| 登录失效或出现验证码 | 在 Page 中完成登录或人工验证，再刷新账号状态 |
| 视频无法理解 | 检查 FFmpeg、STT 和视觉 Provider；仍可使用 `metadata` 读取作品信息 |
| 操作结果为 `unknown_result` | 先查看 Page 和原请求的回执，不要立即重复发送；动作可能已经提交 |

## 当前限制

- 当前为预发布版本，真实账号与在线页面兼容性仍待验证。尤其 @、私信和原生视频转发处于实验阶段，页面改版或身份信息不足时可能不可用。
- 作品引用支持数字 ID 或 `https://www.douyin.com/video/ID` 标准链接，暂不支持抖音短链接。
- Page 提供定时刷新的浏览器画面，不包含远程音频播放流。
- 抖音站内转发与分享到 QQ、微信等聊天平台是不同操作；后者交给 AstrBot 已有的消息发送能力。
- 本插件提供抖音工具；人格、长期记忆、关系状态和主动互动策略由 AstrBot 与其他插件负责。

登录状态和操作记录保存在 AstrBot 数据目录。Page 使用当前 Dashboard 登录身份访问，与你的 Bot 共用本插件的抖音会话。
